# Agent notes

- This repo ships a Claude Code skill — instructions and scripts that run as
  the installing user. Never weaken the send guard, credential protections,
  or the "Claude never sends" rule without an explicit reason in the PR.
- Scripts print counts and row numbers only — never contact values, never
  credentials. Keep them small, readable, and network-free.
- `skills/messengerr/references/commands.md` is generated by
  `build/generate_commands.rb` from the installed CLI — don't hand-edit.
- Releases are reproducible: `build/build_tarball.rb` must produce identical
  bytes for identical inputs (CI checks).
- Run `rake test` before pushing. Behavior evals are manual — see
  `tests/evals.md`.
